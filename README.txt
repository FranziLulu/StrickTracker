STRICK TRACKER: SO RICHTEST DU DIE APP EIN

Was enthalten ist
- Gesamtzähler und Zykluszähler
- Zunahmehinweis bei jeder 8. Reihe (oder deiner eingestellten Zykluslänge)
- Reihe zurücknehmen
- Separate Zähler für Sophie Hood, Sophie Scarf und ein eigenes Projekt
- Speichert den Stand lokal auf dem Gerät
- Offline-Unterstützung nach dem ersten Laden

Wichtig
Damit du die App auf dem iPhone zum Home-Bildschirm hinzufügen und offline verwenden kannst, müssen die Dateien über HTTPS erreichbar sein. Das ZIP ist noch nicht automatisch im App Store oder im Internet veröffentlicht.

Ein einfacher Weg ist GitHub Pages:
1. ZIP entpacken.
2. Die vier Dateien index.html, manifest.json, sw.js und icon.svg in ein neues GitHub Repository hochladen.
3. In den Repository Settings unter Pages die Veröffentlichung aus dem main Branch und dem Root-Ordner aktivieren.
4. Die veröffentlichte HTTPS-Adresse auf dem iPhone in Safari öffnen.
5. Teilen antippen und „Zum Home-Bildschirm“ auswählen.

Die Zählerstände werden im Browser auf diesem Gerät gespeichert. Browserdaten zu löschen kann gespeicherte Zählerstände entfernen. Wenn du auf einem anderen Gerät oder Browser öffnest, werden die Stände nicht automatisch synchronisiert.
